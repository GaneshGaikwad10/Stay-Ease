Stay-Ease 🏨
Your gateway to effortless stays and smarter hotel management.

Stay-Ease is a full-stack hospitality platform designed to bridge the gap between boutique hotels and modern travelers. The system provides a seamless experience for guests to discover stays, while offering a robust, moderated workspace for hotel owners and site administrators.

🚀 Key Features
👤 For Guests
Smart Search: Browse and filter hotel rooms based on location, price, and availability.

Seamless Booking: Quick and intuitive reservation flow with real-time status updates.

Personal Dashboard: Manage bookings, view stay history, and update profile settings.

🏨 For Hotel Managers
Property Control: Add, edit, and manage hotel listings and room inventory.

Booking Management: Track incoming reservations and manage guest check-ins.

Onboarding Flow: Secure registration system requiring administrative approval to ensure platform quality.

🛠️ For Administrators
User Moderation: Verify and approve/reject Hotel Manager applications to maintain a trusted ecosystem.

System Oversight: Centralized dashboard to monitor all users, hotels, and active sessions.

Security Controls: Ability to revoke access and manage system-wide data integrity.

🛡️ Security & Technical Excellence
The project is built with a focus on enterprise-grade security and clean architecture:

Secure Authentication: Implements HTTP-only cookies and JWT (JSON Web Tokens) for session management.

Role-Based Access Control (RBAC): Strict permission layers to ensure users only access what they are authorized for.

Verified Onboarding: A custom "Inactive-by-Default" workflow for managers to prevent unauthorized listings.

Automated Testing: Core security middleware and user controllers are verified through a suite of Jest unit tests.

🛠️ Tech Stack
Frontend: Angular (Standalone Components, RxJS, Responsive Design)

Backend: Node.js & Express.js

Database: MongoDB with Mongoose ODM

Testing: Jest & Supertest

Authentication: JWT with Cookie-Parser.
